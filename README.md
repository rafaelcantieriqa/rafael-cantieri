# Rafael Cantieri

QA Automation Engineer | Testes de API, Web e Performance

## Sobre mim

QA Automation Engineer com foco em qualidade, confiabilidade e experiência do usuário. Tenho experiência em automação de testes de aplicações web e APIs, trabalhando com JavaScript, TypeScript, Cypress, Playwright e Postman para garantir entregas mais seguras e consistentes.

Meu objetivo é reduzir riscos em releases, validar regras de negócio com eficiência e aumentar a confiança no produto por meio de testes automatizados, regressão e análise de comportamento em diferentes cenários. Também valorizo boas práticas, melhoria contínua e uma cultura de qualidade que envolva toda a equipe.

Sou apaixonado por criar soluções que ajudem a entregar software com mais estabilidade, previsibilidade e melhor experiência para o usuário final.
